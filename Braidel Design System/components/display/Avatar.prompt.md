User avatar with image, or auto initials + deterministic warm fallback color.

```jsx
<Avatar src="/amara.jpg" name="Amara Okafor" size="lg" ring />
<Avatar name="Tasha B" status="online" />
<AvatarGroup>
  <Avatar name="A B" size="sm" /><Avatar name="C D" size="sm" />
</AvatarGroup>
```

Sizes `xs–xl`. Omit `src` to show initials. `ring` highlights featured users; `status` adds a presence dot.
